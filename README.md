# Voting App

A real-time voting application built with React for frontend, Node.js (Express) and MongoDB for backend, and Socket.IO for live vote updates.


## Features

- User login with simple name input
- Voting functionality with single vote per session limit
- Live results that update in real-time using websockets
- Clean and attractive UI with responsive design
- Backend REST API with MongoDB persistence


## Getting Started

### Prerequisites

- Node.js (v14+ recommended)
- MongoDB (local or hosted)
- npm or yarn package manager

### Installation

1. Clone the repository

git clone :https://github.com/Raghu939086/live-voting_application.git


2. Backend Setup

cd voting-backend
npm install


3. Frontend Setup:
cd ../voting_app
npm install

## Running the Application

### Start Backend Server
cd voting-backend
npm start

### Start Frontend (React) Server
cd voting_app
npm start

The app runs at:  
- Frontend: `http://localhost:5173`  
- Backend API: `http://localhost:4000`

## How to Use

- Enter your name on login
- Choose your vote option and submit
- View live results updates
- Once voted, results show and you cannot vote again
